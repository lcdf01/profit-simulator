# profit-simulator
Il Profit Simulator, ciò che andremo a studiare e implementare, è uno strumento decisionale per orizzonti tattico-strategici (3-12 mesi). Dotato di un'interfaccia intuitiva per il management da utenti non-esperti, permette analisi di scenario "What-If" (variazioni prezzi energetici, mix di vendita, turni straordinari, nuovi investimenti).
